## Implementation and validation

Practice starts collapsed. Each condition bank loads on first open. Each question checks independently; select-all uses exact-set scoring. Answers and results remain only in tab memory and can be cleared with Try again or Reset questions. The separate full-exam practice quiz is preserved.

Run `node scripts/check-section-quizzes.cjs` for all question schemas/routes and 9,687 possible answer combinations. The four existing check scripts cover the standalone quiz, posters, videos and podcast. Browser checks cover wrong/right/empty answers, partial and extra multi-select choices, resets, independent questions, navigation, mobile layout, and load-failure recovery.

When changing a question-bank file, bump the data `version` in `section-quizzes.js` and its script query in `index.html` to refresh cached banks.
